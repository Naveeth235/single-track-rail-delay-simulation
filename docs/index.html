About / How to use

Choose single simulation to watch the fictional queue or Monte Carlo to estimate its waiting-time distribution. Set the inputs and press Start. Pause suspends playback or sampling; Reset returns to the beginning. Identical seeds and settings reproduce results. The confidence interval estimates sampling uncertainty in the mean using 1.96 sample standard errors.
