How to use

1. Watch a journey
Choose Single simulation and press Start. Watch the trains cross and check their waiting times.

2. Compare buffers
Increase the buffer and replay to see how the extra waiting changes.

3. Try Monte Carlo
Enable random delays or running-time variation, then Start. Read the mean, confidence interval and distribution.

4. Check the model
Press Run verification to compare against the reference results.
